Import watch readings

Choose Apple Health export.xml, a TCX activity with heart-rate samples, or a compatible CSV or CREW CHECK JSON file. Extract the file from its ZIP first.

Which file should I use?
  • Apple Watch or another device that syncs to Apple Health: export Health data on your iPhone, then select export.xml.
  • Garmin or another activity app that offers TCX: export one activity that includes heart rate.
  • Other watches: use a per-reading export from the companion app. For CSV, use timestamp plus heartRate (bpm) or spo2 (percent). Each timestamp must include a time zone. Daily averages are not individual readings.

What to do next

Cloud AI reviews finding categories from the simulated check-in.

    Optional local Qwen3

    Qwen3 runs on this device. First use on the web downloads about 2.3 GB.

    How to start local AI

    On Windows, double-click Start-Crew-Check.cmd in the extracted project folder. It downloads missing files, starts the server, and opens your browser.

    Manual setup:

    1. Open a terminal in the extracted CREW CHECK project folder.
    2. While online, run node scripts/prepare-offline-ai.js and wait for “Offline assets ready.”
    3. Run node server.js and leave the terminal open.
    4. Open http://localhost:8080/ in a WebGPU-enabled browser, then choose Health Monitoring System → Action plan → Highlight with local AI.

    On the hosted HTTPS version, the first click downloads the model in the background and displays progress here.
